**Data Volume Monitor**

A plugin that lets you monitor and act on your consumed data volume utilizing vnStat.

The settings page shows the installed **DVM Version / Channel**. Use the
documentation matching that channel:

- [Stable documentation and source (`main`)](https://github.com/alexphillips-dev/Data-Volume-Monitor/tree/main)
- [Development documentation and source (`dev`)](https://github.com/alexphillips-dev/Data-Volume-Monitor/tree/dev)
- [User guide and troubleshooting wiki](https://github.com/alexphillips-dev/Data-Volume-Monitor/wiki)

The first stable release is [2026.11.04.11](https://github.com/alexphillips-dev/Data-Volume-Monitor/releases/tag/2026.11.04.11).
Updates follow the channel recorded in the installed plugin manifest.
Both channels use the same `dvm` plugin identity and configuration/database
locations. Follow the channel-switch instructions in the matching README;
uninstalling deletes plugin configuration and traffic history.
